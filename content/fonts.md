# Self-hosted fonts

The project uses the design system's recommended Lora heading font and DM Sans body font. Both files were downloaded unmodified from the official [Google Fonts repository](https://github.com/google/fonts) on October 22, 2026, and are served locally. Builds and visitor page loads do not need to fetch fonts from Google.

| Font | Local file | Available axes | Source | License |
| --- | --- | --- | --- | --- |
| Lora | `public/fonts/lora/lora-variable.ttf` | Weight: 400–700 | [Lora variable font](https://github.com/google/fonts/blob/main/ofl/lora/Lora%5Bwght%5D.ttf) | [Local SIL OFL 1.1](../public/fonts/lora/OFL.txt) |
| DM Sans | `public/fonts/dm-sans/dm-sans-variable.ttf` | Weight: 100–1000; optical size: 9–40 | [DM Sans variable font](https://github.com/google/fonts/blob/main/ofl/dmsans/DMSans%5Bopsz%2Cwght%5D.ttf) | [Local SIL OFL 1.1](../public/fonts/dm-sans/OFL.txt) |

Lora: Copyright 2011 The Lora Project Authors ([upstream](https://github.com/cyrealtype/Lora-Cyrillic)), with Reserved Font Name “Lora.”

DM Sans: Copyright 2014 The DM Sans Project Authors ([upstream](https://github.com/googlefonts/dm-fonts)).

Each adjacent `OFL.txt` contains the complete original copyright notice and license. Preserve these files when distributing the fonts with this project. Only upright variable files are included; no italic files were downloaded.
